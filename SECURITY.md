# Security Policy

## Supported Versions

We actively support and fix security issues for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability, please do **NOT** report it via public issues or pull requests. Instead, please report it privately:

1. **Email us**: Send a detailed description of the vulnerability to **facio.gabrielemiliano@gmail.com**.
2. **Include Details**: To help us verify and patch the issue, please include:
   - A description of the vulnerability.
   - Step-by-step instructions to reproduce it (proof of concept).
   - Potential impact (e.g., privilege escalation, data exposure).
3. **Response**: We will acknowledge receipt of your report within 48 hours and work with you to resolve the issue as quickly as possible.

Thank you for helping keep this project secure!
